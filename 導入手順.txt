市区町村制覇アプリ：ピンチ操作中の地名ちらつき改善（2026年10月17日）

【対象】
A方式の全国から都道府県をタップして表示する版を導入済みのアプリです。
前回のZIP「municipality_map_prefecture_option_A_20261017.zip」を基準に作成しています。

【今回の変更点】
1. app.js：LeafletのmarkerZoomAnimationを明示的に有効化。
2. app.js：拡大縮小や移動のあと、残る地名はマーカーを使い回すように改善。
3. index.html：更新後のapp.jsが読み込まれやすいよう、読み込み識別子を変更。
4. tests内の4ファイル：地名の表示維持チェックと読み込み識別子のチェックを更新。

【変更しないもの】
訪問記録の保存名・形式／制覇率／県の切り替え／地図の色／バックアップ処理。
style.cssは変更しません。

【変更前のバックアップ】
1. PCとiPhoneでアプリの「JSONを書き出す」を実行し、別々に保管。
2. GitHub Desktopでmunicipality-mapを選択。
3. Changesに未保存の作業がある場合は、内容を確認して先にコミット。
   すでにNo local changesなら、過去のコミットがバックアップになります。

【PCでの上書き手順】
1. このZIPを展開。
2. GitHub Desktop → Repository → Show in Explorerでアプリのフォルダを開く。
3. app.js と index.html をアプリのフォルダ直下の同名ファイルへ上書き。
4. ZIPのtestsフォルダにある4ファイルを
   アプリのtestsフォルダの同名ファイルへ上書き。
   ※ testsフォルダ全体を置き換えず、ZIP内の4ファイルのみ。
5. style.cssやその他のファイルは上書き・削除しない。

【PCでの確認】
・市区町村を選んで記録編集ができる。
・拡大縮小後に地名が大きくちらつかない。
・県を切り替えても前の県が残らない。
・保存した訪問記録がそのまま残っている。
・Node.jsがある場合は、VS Codeのターミナルで node --test tests/*.test.cjs を実行。

【GitHub Pages公開】
1. GitHub Desktop → Changesで上書きした6ファイルだけ変更されていることを確認。
2. Summary に Improve map labels during pinch zoom と入力。

【注意】
自動テストは模擬環境です。実際のiPhoneでの見え方はユーザーによる確認が必要です。
Leafletの標準動作やブラウザによりピンチ中の表示に違いが残る可能性があります。
うまく表示されなくても、ブラウザのサイトデータは削除しないでください。
問題があれば、変更前のGitHubコミットに戻してください。
