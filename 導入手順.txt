市区町村制覇アプリ — 詳細な行政区域境界 2026年版

【今回の目的】
全国表示には従来の軽量地図（2021年データの0.1%簡略化版）を使い、都道府県を選ぶか地図を拡大したときだけ、2026年行政区域データの5%簡略化版を読み込みます。
日本の地形背景、訪問記録、JSONバックアップ、自動復元処理は変更していません。

【変更ファイル】
- app.js（上書き）
- index.html（上書き）
- tests/map-boundary-detail.test.cjs（追加）
※ style.css や既存の tests/*.test.cjs を削除・変更しないでください。
※ 今回のZIPは前回の「地形表示・詳細境界版」ZIPのapp.js/index.htmlを土台にしています。

【公開までの手順】
1. iPhoneから「JSONを書き出す」で訪問記録をバックアップし、iCloud DriveやPCにも保管します。
2. GitHub Desktopで未コミットの変更がないことを確認します。
3. 今回のZIPをWindowsの「すべて展開」で展開します。
4. GitHub Desktopで Repository → Show in Explorer を開きます。
5. ZIPの app.js、index.html をリポジトリの同名ファイルに上書きします。
6. ZIPの tests/map-boundary-detail.test.cjs をリポジトリの tests フォルダへ追加します。
7. GitHub Desktopで変更ファイルが2件、追加ファイルが1件であることを確認します。
8. Summaryに Improve detailed municipality boundaries と入力し「Commit to main」→「Push origin」を実行します。
9. GitHub Pagesで反映されたことを確認します。実データのJSONインポートやリセットは試さないでください。

【確認項目】
- PC・iPhoneの全国表示では地形・色分けが従来どおり表示される。
- 都道府県（例：北海道）を選ぶと「詳細境界を表示中（2026年...）」に変わり、境界の細部が増える。
- 全国表示に戻してから拡大率8以上にすると、拡大部分で詳細境界が表示される。
- 市区町村の表示を押すと記録編集画面が開く。
- 訪問済み件数、制覇率、JSON書き出し・復元ボタンが以前と同じである。
- 詳細データの通信が失敗しても従来の地図が表示される。

【注意事項】
詳細境界は2026年1月1日基準の5%簡略化データであり、正式な測量上の境界線と完全に一致するものではありません。面積5万m2未満の小島等は詳細データから省かれていることがあります（従来データを一部残す仕組みです）。
2021年の全国データと2026年の詳細データで境界変更がある場合、拡大前後に多少の差が出ます。
データを表示できなかった場合、自治体の通常の境界に戻り、訪問記録を変更しません。
