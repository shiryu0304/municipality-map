市区町村制覇アプリ — 小さな町村名も表示・地名描画の軽量化
作成日：2026年10月17日
対象：shiryu0304/municipality-map
基準：前回の「地図の軽量化・全画面表示改善版」（municipality_map_pan_fullscreen_improvement_20261017.zip）

■ 今回の変更
1. 都道府県の詳細地図に含まれる自治体名を、件数上限・重なり判定によって省略しなくなりました。
2. 区域の幅と高さから文字の目安サイズを決め、狭く縦長の区域は縦書きを使用します。
3. 地名マーカーを県ごとに一度だけ作り、画面移動や拡大縮小のたびには作り直さなくしました。
4. フォント倍率を地図全体のCSS変数で変更し、ズームごとのDOM更新を抑えます。
5. 詳細境界の描画を少し簡略化し、以前開いた県の地名位置も再利用します。

※ 「全自治体名」＝使用中の県別境界データと自治体一覧が対応付けられた区域です。
   境界データに欠落や不一致がある自治体の位置は自動生成できません。
※ 非常に狭い地域では7pxより小さくしないため、重なったり区域からはみ出したりします。
※ 端末・通信・地図データの量によって負荷は変わります。完全にカクつかない保証はありません。
※ 地図の全画面表示、色分け、県の選択、訪問記録の保存形式は変更していません。

■ まずバックアップ
1. PCの公開アプリで「JSONを書き出す」を押し、記録ファイルを保存します。
2. iPhoneでも「JSONを書き出す」を押し、別の場所に記録ファイルを保管します。
3. GitHub Desktopを起動し、左上に municipality-map と表示されていることを確認します。
4. 「Changes」に未コミットの変更があれば、内容を確認し、必要なら先にコミットしてください。
5. 元のアプリのフォルダを、別の場所にコピーしておくとさらに安心です。

■ コピーするファイル（修正版ZIPを展開した後）
【アプリ本体：3ファイル】
  ZIPの app.js       → municipality-map/app.js
  ZIPの index.html   → municipality-map/index.html
  ZIPの style.css    → municipality-map/style.css
【テスト：7ファイル】
  ZIPの tests/ 内にある各ファイル → municipality-map/tests/ 内の同名ファイル

手順：
1. ZIPファイルを右クリックし「すべて展開」を選びます。
2. GitHub Desktopのメニュー「Repository」→「Show in Explorer」を開きます。
3. エクスプローラーで municipality-map フォルダを開きます。
4. 展開した3ファイルを同名の場所へコピーし「ファイルを置き換える」を選びます。
5. ZIP内の tests フォルダの7ファイルを、既存の tests フォルダへ上書きします。
6. その他のファイルやフォルダを削除しないでください。

■ PCでテスト
1. VS Codeでプロジェクトフォルダ municipality-map を開きます。
2. Live Serverを利用して index.html を開くか、公開前のローカル動作を確認してください。
3. 青森県や東京都などを選び、町村名が小さい文字や縦書きで表示されることを確認します。
4. 拡大縮小や画面移動を繰り返し、地名が消えずに追従するか確認します。
5. 市区町村を押し、訪問・通過・未踏、制覇率が正しく変わるか確認します。
6. Node.jsをインストール済みの場合は、VS Codeのターミナルから「node --test」を実行できます。
   （実行しなくても公開はできますが、実行できる場合は結果を確認してください。）

■ GitHub Pagesへ公開
1. GitHub Desktopに戻り、Changesに想定した変更ファイルだけが並ぶことを確認します。
2. Summary欄に「Show all municipality names and optimize map labels」などと入力します。
3. 「Commit to main」を押してから「Push origin」を押します。
4. https://shiryu0304.github.io/municipality-map/ をPCで開き、更新されたことを確認します。
5. iPhoneのSafariでも再読込して確認し、ホーム画面版でも確認します。
   ※ iPhoneで古い表示のままでも、訪問記録を守るためサイトデータは消さないでください。

■ 確認ポイント
- 県別地図で、これまで省略されていた町村名も表示される。
- 縦長の市町村では縦書きの地名が表示されることがある。
- 大きい区域は大きい字、小さい区域は小さい字となる。
- 地図を動かして元の位置へ戻しても地名が再生成されず、極端なちらつきがない。
- 地名が地図のタップや記録編集の邪魔をしない。
- 全国地図からの県選択、全画面、色分け、JSON書き出し・読み込みに異常がない。
- PCとiPhone Safari、iPhoneホーム画面版で両方チェックする。

訪問記録をJSONで保管した上で、GitHub Desktopで前回の正常なコミットを選び、
戻す方法を相談してください。ブラウザのサイトデータ消去は行わないでください。
