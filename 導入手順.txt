市区町村制覇アプリ：全国地図から都道府県をタップして詳細へ進む（A方式）
対象: shiryu0304/municipality-map
作成日: 2026-10-17

■ どのように変わるか
・最初の地図は47都道府県の概観。県ごとの訪問率（訪問自治体数÷対象自治体数）で塗り分けます。
・地図上の県をタップ／クリックすると、その県だけの市区町村境界を取得・表示します。
・従来の都道府県選択欄からも同じ操作ができます。
・「全国表示に戻す」で47都道府県の地図に戻れます。
・最後に読み込んだ県の詳細地図データを最大3県分再利用します。
・全国の市区町村境界を起動時に一括取得する処理をなくしました。
・記録の保存形式（municipality-conquest-records-v1）、JSONの取り込み／書き出しは変更していません。

■ コピー／上書きするファイル
ZIP内の「app.js」「index.html」「style.css」をリポジトリ直下の同名ファイルに上書き。
ZIP内「tests」フォルダの9個の .test.cjs ファイルを、リポジトリ内の「tests」フォルダに同名で上書き。
ほかの既存ファイルは削除しないでください。「導入手順.txt」は読むだけで結構です。

■ 更新前のバックアップ（最重要）
1. iPhoneで公開アプリを開き「JSONを書き出す」を押して、記録ファイルを「ファイル」アプリ等に保存。
2. PC側にも訪問記録がある場合、PCのブラウザでも「JSONを書き出す」で別途保存。
   ※訪問記録は端末・ブラウザごとの保存です。GitHubの変更では同期されません。
3. WindowsのGitHub Desktopを開き、左上で「municipality-map」を選択。
4. Changesに未コミットの変更があれば確認し、現在の安全な状態として先にコミットしてください。
   「No local changes」であれば、既存の直近コミットが復旧の基点になります。
5. 念のためリポジトリ全体を別フォルダへコピーして保管すると、戻す操作がさらに簡単です。

■ Windowsでの導入手順
1. このZIPをダウンロードして、右クリック →「すべて展開」で展開。
2. GitHub Desktop → Repository → Show in Explorer を押して、実際のリポジトリフォルダを開く。
3. 展開フォルダから app.js / index.html / style.css を実際のリポジトリの同名ファイルにコピーして上書き。
4. 展開フォルダ内 tests の .test.cjs ファイル9個を、リポジトリの tests にコピーして上書き。
5. GitHub Desktop の Changes タブで、意図しないファイルの追加・削除がないか確認。
6. PCのブラウザで先に動作を確認。VS Code の Live Server が使える場合は、index.htmlをそれで開く（ネット接続が必要）。
7. Node.js をインストール済みなら、VS Codeのターミナルでプロジェクトのルートを開き、下記を実行。
   node --test tests/*.test.cjs
   ※Windows PowerShellでワイルドカードが展開されず失敗する場合は、node --test tests をお試しください。
8. 問題なければ GitHub Desktop の Summary に「Add lightweight prefecture picker map」と入力。
9. 「Commit to main」→「Push origin」でGitHubへ送信。
10. GitHub Pagesの公開URLでPC・iPhoneともに確認。
   https://shiryu0304.github.io/municipality-map/

■ PCの動作確認
□ 全国画面で都道府県の輪郭が表示され、色が訪問率に対応する。
□ 県の地図をクリックすると、その県だけの市区町村境界が表示される。
□ 県内の地域をクリックすると、「記録を編集」から編集できる。
□ 訪問を登録すると市区町村の色・制覇率が更新される。
□ 「全国表示に戻す」で県別の訪問率の地図になる。
□ 東京都→大阪府→東京都と切り替えても古い地域の図形が残らない。
□ 検索、JSON書き出し、JSON読み込み、過去記録の復元が変わらず動作する。
□ 全画面表示を開閉しても地図が崩れない。

■ iPhoneでの動作確認
□ Safariで全国地図上の県をタップして切り替えられる。
□ ピンチで拡大／縮小、1本指で移動できる。
□ 県内の市区町村をタップできる。編集後も記録が保持される。
□ 県から全国へ戻れる。全画面表示でもボタンを操作できる。
□ ホーム画面に追加したアプリでも同様か確認する。
※キャッシュで旧画面が出る場合は、まずSafariでURLを開き直して比較してください。訪問記録を守るため、安易に「Webサイトデータを消去」しないでください。

■ 確認できたことと未確認のこと
Node.jsの模擬テスト44項目に合格し、JavaScript構文チェックに合格。
ただし、実際のGitHub Pagesへの公開、外部サイトの配信速度、PCブラウザでの操作、iPhone Safariでの描画は確認していません。
県境・自治体境界は公開データに依存するため、通信障害やデータ更新による地図の欠損が起こる可能性があります。
離島の多い都道府県では、県内の全域を表示すると本土部分が小さく見える場合があります。

■ 元に戻す方法
訪問記録のJSONを大切に保存したうえで、GitHub DesktopのHistoryから、変更前の状態へ戻してください。
コードのロールバックは各端末の訪問記録を自動復元するものではありません。
不具合を見つけた場合は、OSやブラウザ、選択した都道府県、操作手順をメモして相談してください。
