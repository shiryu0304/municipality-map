市区町村制覇アプリ：全国地図の表示範囲・余白の改善
対象リポジトリ：shiryu0304/municipality-map
公開URL：https://shiryu0304.github.io/municipality-map/

【変更したファイル】
1. app.js ：全国表示に上下左右の余白を追加。都道府県表示にも適度な余白を追加。
2. style.css ：地図の高さをPC 540→650px、スマートフォン 430→530pxに変更。
3. tests/map-japan-only.test.cjs ：全国表示とリセット時の余白・地図の高さを検査。

【変更しない内容】
訪問記録のlocalStorage保存名・保存形式、JSONの書き出し・読み込み、
読み込み前の自動バックアップ、地形タイル・市区町村の境界と詳細境界データ。
index.htmlおよび他のテストファイルは変更しません。

【導入手順（Windows + GitHub Desktop）】
1. iPhoneのアプリから「JSONを書き出す」で記録をバックアップしてください。
2. GitHub Desktopで municipality-map リポジトリを選択し、未コミットの変更がないことを確認。
3. 本ZIPファイルを右クリック →「すべて展開」。
4. GitHub Desktop の Repository → Show in Explorer をクリック。
5. ZIP内の app.js、style.css を開いた municipality-map フォルダへ上書きコピー。
6. ZIP内の tests/map-japan-only.test.cjs を municipality-map/tests フォルダへ上書きコピー。
   既存の import-safety.test.cjs、map-boundary-detail.test.cjs は消さないでください。
7. GitHub Desktop の Changes で変更されたファイルが上の3件だけなのを確認。
8. Summary: Improve nationwide map framing
   Commit to main → Push origin で公開。
9. 数分後に https://shiryu0304.github.io/municipality-map/ で表示を確認。

【公開後の確認事項】
・全国地図で北海道の上側や沖縄の下側に十分な余白がある。
・PCとiPhone Safari・ホーム画面アプリで地図が見やすい。
・都道府県選択、拡大、全国表示に戻すが動作する。
・地形、詳細境界、市区町村名、色分けが従来どおり表示される。
