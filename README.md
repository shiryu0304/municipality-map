# 全国市町村制覇 v0.5

## v0.5の追加・変更点
- 都道府県別の訪問済み自治体数・制覇率を表示
- 東京都の特別区23区を対象に含め、政令指定都市の行政区は対象外
- 都道府県の進捗カードを押すと、市町村一覧をその都道府県に絞り込み
- 訪問済みの判定基準を記録画面に明記（滞在時間は問わず、実際にその自治体を訪れたら訪問済み）
- 訪問日は未設定なら空欄のまま。複数の日付・滞在期間を登録可能
- 既存の地図・自治体一覧・JSONバックアップ機能を維持

## 2026年10月22日：完全制覇の特別色と日本地図アイコン
- 地図の表示設定「100%制覇した県を金色で表示」を追加。初期値はON。OFFにすると従来どおり75～100%は緑になります。
- 全国地図と都道府県別の制覇率カードに同じ表示設定を反映します。色の変更は外観のみで、訪問記録・達成率の集計方法は変更しません。
- ON/OFFはブラウザごとに保存されます。JSONバックアップへ設定は含みません。
- スマホ下部メニューの「地図」アイコンを、日本列島のシルエットSVG（`japan-map-nav.svg`）に変更しました。

## 2026年10月22日：バックアップと履歴、スマホ操作の改善
- 登録済みの訪問・通過日を新しい順に確認できる「訪問履歴」を追加。日付未設定は末尾に表示します。
- 訪問履歴は最初は表示せず、「カテゴリー」で「訪問・通過すべて／訪問のみ／通過のみ」を選んだ場合だけ一覧を表示します。カテゴリーを未選択に戻すと一覧は消えます。
- カテゴリー選択後に自治体名で検索でき、30件ずつ続きを表示できます。これは記録の更新日時の履歴ではありません。
- バックアップの「前回のJSON書き出し操作日時」を表示（実際に保存されたかはファイルアプリなどで確認が必要です）。
- 訪問記録をリセットする前に、同じブラウザ内に1回分を自動退避し、復元できるようにしました。次回リセットでは上書きされます。**ブラウザのデータを消すと退避データも消えます**。
- 既存の「読み込み前の記録に戻す」は継続。スマホでは画面下に「ホーム / 地図 / 検索 / 履歴 / 保存」の移動メニューを表示。
- 自治体コード、保存先キー、既存訪問日・メモ、地図描画は変更しません。

## 起動方法
1. ZIPを展開します。
2. 展開したフォルダをVS Codeで開きます。
3. Live Serverで `index.html` を開きます。
4. 自治体一覧・地図データを取得するためインターネット接続が必要です。

## 記録について
訪問記録はブラウザの `localStorage` に保存されます。ブラウザや端末の変更に備え、定期的に「JSONを書き出す」でバックアップしてください。バージョン更新時も、先にバックアップすることをおすすめします。

## データについて
自治体一覧と境界データは外部の公開データを取得しています。データの更新時期やコード体系の違いにより、自治体数・名称・境界が現在の行政区域と一致しない場合があります。
