市区町村制覇アプリ　地図操作の滑らかさ改善（第1段階）
2026年10月18日

【何を変えたか】
1. 拡大・縮小の刻み幅を細かくしました。
   ・マウスホイールでの拡大・縮小を穏やかにしました。
   ・画面左の＋／−ボタンでも半段ずつ拡大・縮小します。
   ・iPhoneの2本指による拡大・縮小の終了位置を4分の1段刻みにしました。
2. ドラッグ後の惰性移動が極端に速くならないように設定しました。
3. 県を選ぶとき、詳細地図の読み込み完了後に表示位置をもう一度変更する動作を避けました。
4. 拡大・縮小を終えた後の地名サイズの更新を250ミリ秒待たず実行し、
   県境の太さを変更する必要がないときは再描画しないようにしました。
5. JSファイルを古いキャッシュから読み込まないよう、index.htmlの読み込みURL末尾を変更しました。

【変更したファイル（2つ）】
・app.js : 地図の拡大・縮小、ドラッグ、表示位置更新の処理
・index.html : app.jsの読み込みURL（キャッシュ対策）

【任意のテストファイル】
・tests/map-boundary-detail.test.cjs : 上記の挙動に対する2件の自動テストを追加

【作業前に必ず行うこと】
(1) 公開中のアプリをPC・iPhoneで開き、どちらでも「JSONを書き出す」を実行して訪問記録を退避してください。
    記録はブラウザごとに保存され、GitHubのコミットとは別です。
(2) GitHub Desktopを開き、現在の変更が残っていればコミットしてから進めてください。
    コミットしない変更がある場合は、そのファイルを別の場所にもコピーしてください。
(3) エクスプローラーで既存の municipality-map フォルダを一式コピーし、
    municipality-map_backup_20261018 などの名前にして残しておくと安心です。

【導入手順：Windows】
(1) このZIPを右クリック→「すべて展開」を選びます。
(2) 展開先を開き、app.js と index.html の2ファイルを確認します。
(3) VS Codeで、いつも編集している municipality-map のフォルダを開きます。
(4) VS Codeの左側にある app.js と index.html が置かれているフォルダを
    Windowsのエクスプローラーで開きます（VS Codeから対象を右クリック→エクスプローラーで表示）。
(5) 展開した app.js と index.html を既存の同名ファイルと入れ替えます。
    ※フォルダを丸ごと削除したり、.gitフォルダを上書きしたりしないでください。
(6) testsフォルダでNode.jsのテストを利用している場合のみ、ZIPの
    tests/map-boundary-detail.test.cjs も既存の同名ファイルと入れ替えます。
(7) GitHub Desktopの「Changes」タブで変更されたファイルを確認します。
(8) Summary欄に「地図の操作を滑らかにする」と入力し、Commit to mainを押します。
(9) Push originを押します。GitHub Pagesへの反映を確認します。
(10) PCではブラウザで公開URLを開いてCtrl+F5で再読み込みします。
     iPhoneでは最初にSafariで公開URLを直接開き、表示を確認します。
     ホーム画面に追加したWebアプリはキャッシュが残ることがあります。

【PCで確認すること】
・ホイールの拡大縮小が細かくなったか
・マウスで移動するときの追従具合／ドラッグ終了後の自然さ
・県を選んだあと、詳細データ到着時に視点が急に動かないか
・地名、境界線、訪問／通過／未踏の色分けが表示されるか
・市区町村を押して記録を編集できるか

【iPhoneで確認すること】
・2本指のピンチイン／アウトで地図が操作できるか
・1本指の移動でカクつきや意図しないスクロールがないか
・全画面表示／解除が正しくできるか
・詳細地図の読み込み後も地名と境界線が表示されるか
・JSONバックアップの書き出しが利用できるか

【テスト結果】
Node.jsでの模擬環境における自動テスト：55件中55件合格
JavaScript構文チェック：合格
実機のPCブラウザ／iPhoneのSafari／GitHub Pages公開後の操作感：未検証
