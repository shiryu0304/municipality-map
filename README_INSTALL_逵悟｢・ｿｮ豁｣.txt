市区町村制覇アプリ：県境を市区町村境界に合わせる修正
基準：ユーザー提供 municipality-map(3).zip（2026-10-18）

■変更するファイル（3ファイル）
1. index.html
   新しいJavaScriptを確実に読み込むため、読み込みURLの識別子だけ変更。
2. maplibre-main.js
   県選択中は旧来の粗い県境を隠し、詳細データから生成した県境を表示。
3. maplibre-map-logic.js
   同じ県内の市区町村で共有する線分を取り除き、外周線だけ生成。

■追加するテスト（任意。アプリ画面には影響しません）
tests/map-prefecture-detail-outline.test.cjs

■作業前に必ず実施
(1) PCとiPhoneそれぞれのアプリから訪問記録のJSONバックアップを保存。
(2) GitHub Desktopでmunicipality-mapを選択し、変更がないことを確認。
    変更があれば先にコミット。必要に応じてPush。
(3) 念のため、現行の3ファイルのコピーを別フォルダに保存しておく。

■インストール（Windows）
(1) このZIPファイルを右クリック→「すべて展開」。
(2) 展開したフォルダ内の上記3ファイルを選択してコピー。
(3) VS Codeで開いている municipality-map のフォルダをエクスプローラーで開く。
(4) そのフォルダに貼り付け、「ファイルを置き換える」を選択。
(5) テストも残す場合、tests フォルダ内の新規テストを、既存の tests にコピー。
(6) GitHub Desktopの「Changes」で3ファイル（＋テスト）の変更を確認。
(7) Summaryに「県境と市区町村境界を一致させる」と入力し「Commit to main」。
(8) 「Push origin」をクリックし、GitHub Pagesの反映後にブラウザで確認。

■確認項目
PC / iPhone共通：
- 全国地図と県選択が問題なく表示される。
- 都道府県を選び、詳細が読み込み終わると太い県境が市区町村の線と重なる。
- 特に県境を拡大しても、旧来の粗い別線が浮いていない。
- 県を切り替え、全国に戻し、もう一度県を選んでも正常に表示される。
- 地図のタップ・ズーム・移動、訪問の色分け・編集が今まで通り機能する。
- 訪問記録・制覇率が変わっていない。

■既知の制約
- 全国表示中は起動速度のため従来の簡略化データを使う。県を選んで
  詳細データの読み込みが完了した段階で境界線を正確に重ねる。
- 地図データ自体は簡略化されたもの。公的な測量精度を保証するものではない。
- データの実配信とPC/iPhoneでの最終確認はユーザー側で行う。
- 地図データの元に相互に一致しない内部線分が含まれる場合は、
  一部の線が残る可能性がある。その場合は県名・地点を教えてください。

municipality-map 内で「node --test tests/*.test.cjs」
