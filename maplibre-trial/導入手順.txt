市区町村制覇アプリ MapLibre試作版 v4（地図起動エラー修正版）
2026年10月18日

【確認できた原因】
ユーザーから送られた診断 v3 の画面：
  JavaScript エラー: TypeError: maplibregl.supported is not a function. (462行)

MapLibreライブラリは読み込まれていますが、app.jsが利用できない関数
maplibregl.supported()を呼んで、その時点で止まっていました。

【今回の変更】
・maplibre-trial/app.js：存在しない関数の呼び出しを削除。
  WebGLの起動失敗は地図生成時のエラーとして表示する方式に変更。
・maplibre-trial/bootstrap.js：app.jsのバージョンを4に変更し、古いキャッシュを避ける。
・maplibre-trial/index.html：表示を「診断 v4」に変更、読み込み用の番号を4へ更新。
・maplibre-trial/tests/：このエラーが再発しないようテスト追加・更新。
・maplibre-trial/map-logic.js、style.css：変更なし。
・元のアプリ index.html、app.js、style.css：変更なし。

【導入前のバックアップ】
1. 元のアプリで訪問記録のJSONを保存します。PCとiPhoneで別々に使っている
   場合は両方で書き出します。
2. GitHub Desktopを開き、現在の作業内容を確認して必要ならコミットします。
3. 可能なら municipality-map フォルダも別の場所へコピーしておきます。

【導入手順】
1. ZIPを右クリックして「すべて展開」を選びます。
2. 展開した「maplibre-trial」フォルダを、既存の「municipality-map」
   フォルダの中へコピーします。既存ファイルの置き換えを選択します。
3. GitHub Desktopの Changes で、変更されたファイルが
   「maplibre-trial/」の中だけであることを確認してください。
4. 左下のSummaryに「MapLibre v4 地図起動エラー修正」と入力し、
   「Commit to main」→「Push origin」をクリックします。
5. 公開が反映されたら、下記のURLから新しいページを開いてください。
   https://shiryu0304.github.io/municipality-map/maplibre-trial/?check=v4-20261018
6. 地図の下が「診断 v4」と表示されることを確かめてください。

【PCとiPhoneでの確認】
・最初に日本の都道府県の輪郭が表示されるか。
・「診断 v4」にエラーが表示されていないか。
・PC：マウスドラッグとホイールで滑らかに移動・拡大縮小できるか。
・iPhone：1本指で移動、2本指で拡大縮小できるか。
・県を選んだとき、市区町村の地図と訪問済みの色が表示されるか。
