MapLibre試作版 v5：元アプリに近い地図表示（2026-10-18）

【変更したもの】
 maplibre-trial/app.js：訪問色と境界線の太さ、県境を前面に、全地名表示を優先
 maplibre-trial/map-logic.js：狭い自治体の文字サイズ・縦長の自治体名の配置情報
 maplibre-trial/index.html：表示文言と新バージョンの読み込み指定
 maplibre-trial/bootstrap.js：キャッシュ対策（app.js?v=5）
 maplibre-trial/tests/display-parity.test.cjs：追加の確認用テスト

【元アプリは安全】
 元の index.html、app.js、style.css は一切変更しません。
 元アプリの訪問記録 localStorage は読み取りのみ。書き込み・削除はしません。
 MapLibre試作版で記録の編集はできません。

【導入手順】
 1. 元アプリでJSONバックアップを取ります。PCとiPhoneで別の記録があれば両方保存してください。
 2. GitHub Desktopで作業中の変更をコミットし、Pushして保管します。
 3. ZIPを右クリック→「すべて展開」。
 4. 展開後の maplibre-trial フォルダを、既存の municipality-map フォルダへ上書きコピーします。
 5. GitHub DesktopのChanges画面で変更が maplibre-trial の中だけであると確認します。
 6. Summaryへ「MapLibre地図の県境と自治体名を改善」と入力 → Commit to main → Push origin。
 7. 公開後は https://shiryu0304.github.io/municipality-map/maplibre-trial/?check=v5-20261018 で確認。

【確認項目】
 PC：都道府県を選ぶ→訪問=緑、通過=橙、未踏=淡い色、県境が太く表示。全自治体名を表示。マウス移動とホイールが滑らか。
 iPhone：都道府県切替、1本指で移動、2本指で拡大縮小。画面全体・全画面表示。県境・地名が正しい。
 注意：地名は重ならないよう間引くのではなく、見えることを優先したため、密集地域で重なります。
 どちらもJSONを読み込んだ場合は色分けが変わることを確認。元アプリの記録は変更されません。
 問題があれば診断 v5 の赤いエラー内容と画面をお知らせください。
