市区町村制覇アプリ MapLibre試作版 v3（診断付き）
2026年10月18日

【不具合の状況】
地図が水色のままでエラー文も出ないという報告を受け、原因を特定できるようにしました。
公開中のファイルが旧版のままか、MapLibreの配信元・WebGL・コード・地図データの
どこで停止しているのかは、現時点では特定できていません。

【修正のねらい】
・地図が動かなくてもHTML単体で「診断 v3」と停止箇所を表示します。
・地図描画用ライブラリは、配信元Aが失敗したら配信元Bを試します。
・地図プログラムのJavaScriptエラー、データ通信エラーを画面に出します。
・トップの表示に「試作版 v3・診断付き」と明示し、旧版かどうか区別できます。

【変更したファイル】
maplibre-trial/index.html: 初期診断欄と新しい読み込み方式
maplibre-trial/style.css: 診断欄の色分け
maplibre-trial/app.js: 地図起動とデータ取得の報告
maplibre-trial/bootstrap.js: 地図ライブラリの読み込みと自動切り替え（新規）
maplibre-trial/tests/diagnostic.test.cjs: 自動テスト（新規）
その他のファイルは前回の修正版と同じです。
「municipality-map」直下の元アプリ本体は変更しません。

【導入前のバックアップ】
① 元のアプリで訪問記録をJSONに書き出します（PC・iPhoneそれぞれ必要に応じて）。
② GitHub Desktopで未コミットの変更があればコミットします。
③ 念のため現在のmunicipality-mapフォルダをコピーして保管します。

【導入方法】
① ZIPを右クリックして「すべて展開」。
② 展開したmaplibre-trialフォルダを、既存のmunicipality-mapフォルダにコピー。
③ 同じ名前のファイルは「コピー先のファイルを置き換える」。
④ VS Codeで municipality-map/maplibre-trial/ 内の bootstrap.js が追加されていることを確認。
⑤ GitHub DesktopのChangesで変更がmaplibre-trial内だけであることを確認。
⑥ Summaryに「MapLibre試作版 v3 診断機能」と入力してCommit to main。
⑦ Push originを押して公開の反映を待ちます。
⑧ Chromeの新しいシークレットウィンドウで以下のURLを開いてください。
https://shiryu0304.github.io/municipality-map/maplibre-trial/?check=v3-20261018

【確認ポイント】
・上部に「試作版 v3・診断付き」と表示されますか？
・地図の下に「診断 v3」という文字が表示されますか？
・15～20秒後、診断 v3 の右側にどんな文章が出ていますか？
・表示に成功した場合は PCのホイールとドラッグ、iPhoneの二本指拡大縮小を確認。

【結果の伝え方】
地図が表示されない場合は、診断v3欄が見えるスクリーンショット、またはその文章を
そのままChatGPTに送ってください。
「診断v3」が見えない場合、ZIPが正しい場所に置かれていない、Pushされていない、
GitHub Pagesの反映待ち、またはキャッシュの可能性を優先して確認します。
