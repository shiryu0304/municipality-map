市区町村制覇アプリ：バックアップ・訪問履歴・スマホ操作改善版（2026年10月22日）

【このZIPについて】
2026年10月22日「訪問日改善版」を基準にした全ファイル一式です。
現在の訪問記録（各端末のブラウザ内データ）はZIPには含まれません。
既存の自治体コードと訪問記録の保存方式は変更していません。

【更新した内容】
1. 訪問履歴：訪問・通過日を新しい順に表示。複数日、滞在期間、日付未設定に対応。検索と絞り込み、30件ずつ追加表示できます。
2. バックアップ：前回のJSON書き出し操作日時・当時の件数を表示し、同名ファイルの上書きを避けるため、時刻入りファイル名に変更しました。
3. リセット時、同じブラウザ内に1回分のリセット前記録を退避し、「リセット前の記録に戻す」で復元できます。次回のリセットで退避記録は上書きされます。
4. iPhone等の狭い画面では「ホーム・地図・検索・履歴・保存」の下部移動メニューを表示します。地図の全画面表示中は邪魔にならないよう非表示にします。

【更新前に必ず実施すること】
1. 公開中のアプリを開き、「記録のバックアップ」→「JSONを書き出す」を実行してください。
2. ダウンロードしたJSONファイルがPCの「ダウンロード」やiPhoneの「ファイル」に存在することを確認してください。
3. GitHub Desktopで、現在の作業をコミットするか、リポジトリのフォルダを別の場所へコピーしてください。

【Windowsでの導入方法】
1. このZIPを右クリックして「すべて展開」します。
2. 展開してできた「municipality-map」フォルダを開きます。
3. GitHub Desktopを開き、Repository（リポジトリ）→ Show in Explorer（エクスプローラーで表示）を選びます。
4. そのフォルダを開いた状態で、手順2のフォルダ内にあるすべてのファイル・フォルダを、既存のリポジトリへコピーして上書きします。
   注意：リポジトリ全体のフォルダ名を置き換えず、「中のファイルとフォルダ」をコピーしてください。既存の .git フォルダはそのまま残します。
5. GitHub Desktop の Changes（変更）で変更内容を確認します。
6. Commit to main → Push origin の順に操作します。
7. GitHub Pagesへ反映後、PC・iPhoneでページを読み直します。キャッシュの影響が疑われる場合はページを再読み込みしてください。

【確認項目】
・従来の地図、都道府県別制覇率、訪問・通過の数が変わっていない。
・日付未設定の記録が訪問履歴では「日付未設定」と表示され、勝手に今日の日付にならない。
・複数日・滞在期間が履歴に表示され、履歴の「編集」から既存の記録画面を開ける。
・JSON書き出し後、ファイルが端末に存在する。書き出し操作日時が表示される。
・iPhoneの下部メニューで各画面に移動できる。地図の全画面表示中はメニューが隠れる。
・バックアップJSON読み込み、読み込み前復元が従来どおり使える。
・リセットと復元は、必要な外部JSONバックアップを取ったうえでテストしてください。

【重要な注意】
「リセット前の記録」はlocalStorage（そのブラウザ内）に保存する一時退避です。
ブラウザデータを消去した場合や端末を交換した場合は利用できません。定期的なJSONファイル保存が必要です。
「前回のJSON書き出し」は書き出し操作をした日時であり、ダウンロード完了を保証しません。
PC・iPhone実機での公開後の動作は、利用者側で確認してください。
